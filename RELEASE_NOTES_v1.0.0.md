# GDPO v1.0.0

Released 2026-09-21.

This is the first curated public baseline of the Good Design Principles
Ontology. It is deliberately self-contained: it includes the canonical OWL
serialization, local dependency snapshots, synthetic examples, competency
questions, SHACL shapes, and validation tooling.

The release preserves the stable GDPO term IRIs while establishing a distinct
public version IRI. It includes the materials needed to inspect and reproduce
the ontology’s public modeling and validation surface.

The release is intended for semantic annotation, evaluation traceability, and
method development. It is not a design-quality certification or an automated
decision system.
