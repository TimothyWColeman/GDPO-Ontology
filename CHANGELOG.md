# Changelog

This changelog begins with the curated public baseline. It records changes made
in this public repository after that baseline.

## [1.0.0] - 2026-09-21

### Added

- Curated public baseline of the Good Design Principles Ontology.
- OWL ontology, local import catalog, checksum-verified dependency snapshots,
  SHACL shapes, synthetic examples, competency questions, and executable
  validation.
- A criterion–subject assessment pattern for preserving pairings within
  composite design evaluations.
