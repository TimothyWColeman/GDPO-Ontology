# Security policy

GDPO is an ontology and validation toolkit, not a hosted service. Its principal
security concerns are dependency integrity, validation bypasses, unsafe handling
of supplied RDF, workflow compromise, and accidental disclosure through
examples or reports.

## Reporting a vulnerability

Use GitHub’s private vulnerability-reporting feature if it is enabled for this
repository. Otherwise contact the repository owner through the GitHub profile
and request a private reporting channel. Do not place exploit details,
credentials, or sensitive artifacts in a public issue.

Include the affected release or commit, a concise impact statement,
reproduction steps using synthetic data, and any proposed mitigation. No
response-time or remediation service level is promised.

## Supported versions

Security and integrity fixes are considered for the latest tagged public
release on a best-effort basis.
