# Rams-principles mapping

This page gives a readable view of the ten GDPO principle categories. The
canonical OWL axioms remain authoritative: target and process fillers are class
expressions constrained by universal restrictions, not asserted process or
artifact instances. Query contracts [CQ-01](competency-questions.md#cq-01) to
[CQ-04](competency-questions.md#cq-04) provide executable evidence.

| Principle category | GDPO ID | Artifact-associated target | Prescribed process type and lifecycle applicability |
|---|---|---|---|
| Innovativeness | `GDPO0000020` | Design innovativeness (quality; `GDPO0000004`) | Design innovation process (`GDPO0000014`) |
| Usefulness | `GDPO0000021` | Design usefulness (function; `GDPO0000005`) | Design use process (`GDPO0000015`); use and maintenance |
| Aesthetics | `GDPO0000022` | Design aesthetic quality (quality; `GDPO0000006`) | Design aesthetic development process (`GDPO0000030`) |
| Understandability | `GDPO0000023` | Design understandability (disposition; `GDPO0000007`) | Design comprehension process (`GDPO0000016`); use and maintenance |
| Unobtrusiveness | `GDPO0000024` | Design unobtrusiveness quality (quality; `GDPO0000008`) | Design contextual integration process (`GDPO0000031`); use and maintenance |
| Honesty | `GDPO0000025` | Design material honesty (`GDPO0000041`) or design functional honesty (`GDPO0000042`), both dispositions | Design interaction process (`GDPO0000017`), use and maintenance; design communication process (`GDPO0000053`), distribution and use and maintenance |
| Durability | `GDPO0000026` | Design durability (disposition; `GDPO0000010`) | Design endurance process (`GDPO0000018`); use and maintenance |
| Thoroughness | `GDPO0000027` | Design thoroughness quality (quality; `GDPO0000011`) | Design thoroughness assurance process (`GDPO0000032`) |
| Environmental friendliness | `GDPO0000028` | Design lifecycle environmental performance profile (measurement information content entity; `GDPO0000012`) | Design lifecycle-stage process (`GDPO0000019`); sourcing through end-of-life handling |
| Minimalism | `GDPO0000029` | Design minimalism quality (quality; `GDPO0000013`) | Design reduction process (`GDPO0000033`) |

The table is a navigation aid, not a scoring rubric or a claim that an artifact
instantiates any target. Applications needing lifecycle comparison must supply
the relevant product-system, boundary, method, functional-unit, baseline, and
assessment-time information.
