# Overview

GDPO represents design guidance and its evaluation without conflating a
principle with the entity it concerns or a recommendation with an evaluation
outcome. It is intended for applications that need to describe how an artifact
or practice was assessed against one or more of Rams’ ten principles.

The ontology provides a common structure for:

- principle categories and canonical statement information content;
- artifact-associated target expressions;
- process guidance and lifecycle-stage applicability;
- evaluation methods, criteria, and criterion–subject assessment components;
- evaluated artifacts, producing evaluation processes, temporal regions,
  agents, and contextualized scores.

The ontology uses open-world OWL semantics. The accompanying SHACL shapes
provide closed-world checks for the minimum structure of supplied evaluation
records. Neither OWL nor SHACL replaces expert judgment about source meaning or
design quality.

The synthetic examples are deliberately illustrative. They are not empirical
claims about the named products or people.
