# Governance

GDPO changes are reviewed for semantic clarity, identifier stability,
dependency effects, executable evidence, and release impact.

Existing GDPO identifiers are not silently reassigned. A change that alters an
existing definition, axiom, or expected query result must explain its effect,
update the relevant validation evidence, and receive a new public release
version.

Use synthetic examples in issues and pull requests. Do not submit confidential
product records, personal data, credentials, or material that cannot be
redistributed.
